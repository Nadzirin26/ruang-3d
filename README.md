# 3dgs

A beautiful web-based 3D Gaussian Splats viewer built with React, Vite, and [@mkkellogg/gaussian-splats-3d](https://github.com/mkkellogg/GaussianSplats3D).

## Features
- **Auto-Load Default Model**: Loads the default `.ply` automatically on initialization.
- **Glassmorphism UI**: High-quality, modern, and interactive interface.
- **Upload Custom Model**: Easily preview your own `.ply` splats directly in the browser via the floating action button.

## Running Locally
```bash
npm install
npm run dev
```
